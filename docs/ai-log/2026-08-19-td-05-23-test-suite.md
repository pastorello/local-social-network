## 3. What the AI produced

**TD-23 first**, because it gives the hasher a home. `api_client`, `citizen`,
`other_citizen`, `admin`, `make_client` and the autouse `media_root` moved into
`backend/conftest.py` — **112 lines removed** from the three `tests.py`.
`PASSWORD` went to `common/testing.py`: a module rather than a conftest symbol,
so the test modules import it normally (pytest discourages importing conftest).
Module-specific fixtures stayed where they were — `category`/`make_report` in
reports, `make_poll` in polls, `auth_client` in account.

Landed on its own first and measured: **123 passed in 51.55s**, unchanged.
Consolidation does not make anything faster, and it was worth proving that
before changing the thing that does.

`media_root` is now autouse for **every** test rather than for reports only. The
old arrangement was safe by luck — nothing else uploaded — and stopped being
true when the TD-12 avatar tests arrived.

**TD-05 second**: one line, `PASSWORD_HASHERS = ['…MD5PasswordHasher']`, inside
the `if TESTING:` branch that already existed.

**50.53s → 3.31s on the same test set.** Measured by toggling that single line
and re-running, not inferred; stable across three runs (3.31 / 3.38 / 3.31). The
slowest tests are now the settings guards, at 0.31s each, because they spawn a
Python subprocess.

Two tests pin it: one asserts the fast hasher is active under pytest, the other
boots settings in a subprocess and asserts MD5 is **not** there. The second is
the one that matters — MD5 must never be what stores a real password.

**Files:** `backend/conftest.py`, `common/testing.py` (new),
`backend/settings.py`, `backend/tests.py`, and the three `tests.py`, plus
`CLAUDE.md`, `docs/tech-debt.md`, this log + index row.
